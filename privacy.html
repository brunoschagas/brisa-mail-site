Política de Privacidade — Brisa Mail

Última atualização: 16 de novembro de 2026.

Resumo

O Brisa Mail é um aplicativo de email que roda localmente no computador do usuário. Ele não possui servidores próprios e não coleta, armazena nem transmite seus dados para o desenvolvedor.

Quais dados o app acessa

Para funcionar como cliente de email, o Brisa Mail acessa o conteúdo das suas mensagens, remetentes, destinatários e pastas da conta que você conecta. No caso do Gmail, o acesso é feito pelo login oficial do Google (OAuth 2.0), usando o escopo necessário para ler e enviar email.

Como os dados são usados

Os dados das suas mensagens são usados no seu dispositivo, para exibir, organizar, buscar, enviar e responder emails. Nenhum dado é usado para publicidade, vendido ou compartilhado com terceiros para outros fins. Os únicos envios a terceiros são estes:

  • IA sob demanda (Anthropic/Claude): resumir, redigir e revisar enviam o conteúdo do email ou rascunho em questão somente quando você aciona a função, apenas para gerar o texto pedido.
  • Triagem automática de importantes (Anthropic/Claude): se ligada, envia apenas o remetente e o assunto dos emails novos, nunca o corpo, para classificá-los. Pode ser desligada em Ajustes.
  • Fotos dos remetentes: o app consulta o Gravatar com um hash (SHA-256) do endereço do remetente e o serviço de ícones do DuckDuckGo com o domínio do remetente.
  • Imagens dentro dos emails: são carregadas dos servidores indicados pelo próprio email, como em qualquer cliente de email.

Onde os dados ficam

Credenciais e tokens de acesso ficam cifrados com o Keychain do macOS, no seu computador. Para abrir mais rápido, o app guarda no computador uma cópia da lista de mensagens (remetente, assunto, data e marcações; nunca o corpo). O app não envia esses dados para o desenvolvedor.

Google API Services User Data Policy

O uso das informações recebidas das APIs do Google pelo Brisa Mail obedece à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).

Exclusão de dados

Para remover o acesso, saia da conta no app (o que apaga as credenciais e a cópia local da lista) e/ou revogue o acesso do Brisa Mail em myaccount.google.com/permissions.
